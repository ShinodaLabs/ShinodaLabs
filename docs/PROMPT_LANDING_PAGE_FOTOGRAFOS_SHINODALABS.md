# PROMPT — LANDING PAGE DE ALTA CONVERSÃO PARA FOTÓGRAFOS | SHINODALABS

## 1. CONTEXTO DO PROJETO

Quero criar uma landing page profissional, moderna e altamente otimizada para conversão, desenvolvida pela ShinodaLabs e destinada à captação de clientes para fotógrafos, estúdios fotográficos e diretores de imagem.

A landing page será publicada especificamente em:

https://shinodalabs.com/landing-page-fotografos

IMPORTANTE:
- A página pertence ao ecossistema da ShinodaLabs.
- A página será utilizada como destino de campanhas de tráfego pago da ShinodaLabs.
- O objetivo comercial da página é demonstrar uma solução de site especializada para este nicho e gerar leads interessados em contratar a ShinodaLabs.
- Não confundir o objetivo desta página com a captação de clientes para um fotógrafo (casamento, comercial, retrato). Aqui, o cliente da landing page é o FOTÓGRAFO, SÓCIO OU GESTOR do estúdio que poderá contratar a ShinodaLabs.

A página deve funcionar como uma LANDING PAGE COMERCIAL DA SHINODALABS PARA O NICHO DE FOTOGRAFIA.

---

# 2. OBJETIVO PRINCIPAL

O objetivo principal é converter fotógrafos e gestores de estúdios fotográficos que acessarem a página em leads comerciais para a ShinodaLabs.

O visitante deve entender rapidamente:

1. Que a ShinodaLabs cria sites para fotógrafos, estúdios fotográficos e diretores de imagem;
2. Que a solução foi pensada especificamente para este mercado;
3. Que um site profissional é diferente de depender só do Instagram, do Google Meu Negócio, de portais do setor ou de um template genérico;
4. Como a solução pode ajudar na apresentação da marca, dos serviços e do contato;
5. O que a ShinodaLabs entrega;
6. Por que contratar a ShinodaLabs;
7. Qual é o próximo passo para solicitar um orçamento/conversa.

A página NÃO deve parecer um site institucional tradicional da ShinodaLabs.

Ela deve ser uma página de vendas/geração de leads B2B, com comunicação adequada ao nicho, porém premium, profissional e compatível com a identidade da ShinodaLabs.

A página NÃO deve parecer o site de um negócio do nicho. Ela é uma página da ShinodaLabs dirigida a quem decide o site desse negócio.

---

# 3. POSICIONAMENTO DA SHINODALABS

A ShinodaLabs é uma agência especializada em criação de sites e experiências digitais.

Para esta landing page, posicionar a ShinodaLabs como uma empresa que entende que este público não precisa apenas de "um site bonito".

A proposta deve enfatizar:

- Estratégia;
- Design premium;
- UX/UI;
- Conversão (contato, WhatsApp, orçamento, agendamento — conforme o produto do cliente);
- Performance;
- Mobile first;
- SEO local;
- Tracking;
- Estrutura preparada para tráfego pago;
- Clareza na comunicação;
- Construção de autoridade digital da marca do cliente;
- Desenvolvimento sob medida.

Evitar posicionamento de "agência genérica que faz sites para qualquer negócio".

A comunicação deve transmitir especialização no nicho sem afirmar certificações, parcerias oficiais ou expertise operacional do ofício (saúde, CREA, CRC, etc.) sem comprovação.

Campos:

- Texto de privacidade visível antes do envio;
- Botão: "Continuar no WhatsApp".

Comportamento:

- Os dados NÃO são gravados no servidor da página.
- O submit monta uma mensagem pronta e abre `wa.me` com o telefone oficial da ShinodaLabs.
- Se o popup for bloqueado, mostrar handoff com link "clique aqui para continuar".
- Eventos: `form_start` no primeiro foco; `form_submit` + `whatsapp_click` no envio.
- Alternativa de e-mail visível.

Select de momento (adaptar):

- Quero criar o primeiro site;
- Quero renovar o portfólio;
- Quero um site além do Instagram;
- Quero apresentar serviços e tipos de trabalho.

### Acessibilidade e UX

- Skip link "Pular para o conteúdo";
- Header sem menu institucional completo;
- FAQ em `<details>`/`<summary>`;
- `:focus-visible` consistente;
- CTA sticky com `aria-hidden` / `inert` quando oculta;
- Labels explícitos; campos com `autocomplete` e `maxLength`;
- Âncoras `#diferenca`, `#entrega`, `#duvidas-titulo`, `#conversa` e `#privacidade`.

### Tracking

Evento customizado no padrão:

```
shinodalabs:landing
detail: { event, page: "/landing-page-fotografos", placement? }
```

Eventos: `page_view`, `cta_click` (com placement: hero, header, presence, faq, mobile, contact), `form_start`, `form_submit`, `whatsapp_click`, `scroll_50`, `scroll_90`.

Preparar GA4/GTM específicos da campanha, no mesmo espírito das landings de advogados e academias (tags próprias da rota).

### SEO da rota

- Title no formato: "Criação de Sites para Fotógrafos e Estúdios | ShinodaLabs"
- Meta description específica
- Canonical da URL oficial
- Open Graph
- JSON-LD `Service` com provider Organization ShinodaLabs e `areaServed` Brasil
- Keywords: criação de sites para fotógrafos, sites para estúdios fotográficos, portfólio para fotógrafos, ShinodaLabs

### LGPD

Replicar o bloco "Privacidade neste contato":

- Formulário só na memória da página;
- Dados vão para o WhatsApp por escolha do usuário;
- Link para política do WhatsApp;
- Vercel Analytics do site para navegação; campos do form não vão nesses eventos;
- Canal para exercer direitos: e-mail oficial da ShinodaLabs;
- Pedir que o visitante não envie fotos de clientes sem necessidade. Direito de imagem: o site do fotógrafo usará o acervo dele, com as autorizações dele.

### Stack e organização de código (quando implementar neste repositório)

Seguir a estrutura da landing de advogados/academias:

- Rota: `src/routes/landing-page-fotografos.tsx`
- UI: `src/components/photographers/`
- Copy/FAQ: `src/content/photographer-landing.ts`
- CSS scoped com prefixo próprio (`.photo-page`), reutilizando a linguagem visual (dark zinc, grid, glow, orbit) **com acento de nicho**
- Footer compartilhado: `src/components/site/LandingFooter.tsx` (prop `studioLine` com a linha de nicho)

# 10. ESTRUTURA RECOMENDADA

## 01 — HEADER

Mínimo, sticky ou fixo discreto:

- Logo ShinodaLabs (link para `/`);
- Nota: `ESTÚDIO DIGITAL / SOLUÇÕES PARA FOTOGRAFIA`;
- CTA textual: "Vamos conversar" → `#conversa`.

Evitar menu de navegação tradicional se isso prejudicar a conversão.

## 02 — HERO

Mensagem extremamente clara.

Deve responder:

"O que a ShinodaLabs faz para fotógrafos, estúdios fotográficos e diretores de imagem?"

Elementos:

- Eyebrow: `PRESENÇA DIGITAL PARA FOTÓGRAFOS`;
- Headline + destaque em itálico/accent;
- Subheadline;
- CTA principal;
- Caption de baixo risco;
- 3 pontos de prova;
- Mockup premium em browser frame;
- Badge de responsividade.

CTA principal sugerida:

"Quero um site para meu estúdio"

Outras opções podem ser testadas.

Não usar CTA secundária se diluir o foco.

Subheadline de partida:

Um site que apresenta o olhar, esclarece serviços e facilita o contato — com a fotografia no centro e a performance que a maioria dos portfólios ignora.

## 03 — STRIP

Fórmula visual, no padrão da landing de advogados:

ESTRATÉGIA + DESIGN + DESENVOLVIMENTO + PERFORMANCE = UM SITE À ALTURA DO SEU OLHAR.

## 04 — PRESENÇA DIGITAL (3 pilares)

Espelhar a lógica "Apresente / Esclareça / Aproxime":

1. **Apresente** — primeira impressão do olhar, estúdio e linguagem visual.
2. **Esclareça** — tipos de trabalho (casamento, comercial, editorial, retrato, produto), processo, para quem atende.
3. **Aproxime** — WhatsApp, pedido de orçamento, disponibilidade, localização do estúdio.

Fechar com CTA repetida.

## 05 — SOLUÇÃO SHINODALABS (6 entregas)

Cards:

1. Estratégia antes do layout
2. Design com identidade da marca do cliente
3. Conteúdo que orienta (serviços, portfólio, processo, contato)
4. Desenvolvimento sob medida
5. Performance desde a base
6. SEO local e mensuração

Não inventar integrações de software vertical sem a ShinodaLabs realmente oferecer.

Se o briefing futuro incluir embeds (agenda, feed, portal), tratar como possibilidade a avaliar no projeto — não como feature padrão prometida.

## 06 — PARA QUEM É

Lista curta (4 itens), tom de reconhecimento, não de pressão.

## 07 — FAQ

Perguntas reais do decisor + card "tem uma dúvida específica?".

## 08 — CONVERSA / FORMULÁRIO

Padrão WhatsApp da landing de advogados.

## 09 — PRIVACIDADE + FOOTER + STICKY MOBILE CTA

Privacidade: bloco `<details>` com id `#privacidade` imediatamente após o formulário.

Footer publicado (não é faixa mínima). Usar o componente compartilhado `LandingFooter` em `src/components/site/LandingFooter.tsx`.

Desktop — três colunas:
- Marca: logo ShinodaLabs (link `/`), tagline «Design com intenção. Código com precisão.», linha de nicho em uppercase com a cor de acento (`Estúdio digital · soluções para …`);
- Nesta página: A diferença (`#diferenca`), O que entregamos (`#entrega`), Dúvidas (`#duvidas-titulo`), Conversar (`#conversa`);
- Estúdio: ShinodaLabs (`/`), e-mail oficial (`SITE_EMAIL`), Vamos conversar (`#conversa`, evento `cta_click` com `placement: footer`), Privacidade (`#privacidade`);
- Barra inferior: `© {ano} ShinodaLabs. Todos os direitos reservados.` + «Voltar ao site».

Mobile (abaixo de ~760px):
- Uma coluna, tudo centralizado — inclusive o logo. O link `.law-brand` é `display: flex`; no bloco da marca usar `align-items: center` e `justify-content: center` no logo, senão ele fica à esquerda enquanto o texto centraliza;
- Reservar margem inferior quando o CTA sticky estiver visível.

Sticky: CTA fixo no mobile após a seção de presença; oculto (`aria-hidden` / `inert`) no formulário.

# 27. DESIGN

A landing page deve seguir o posicionamento visual premium da ShinodaLabs — o mesmo sistema da landing de advogados/academias — **com paleta de acento do nicho**.

## 27.1 Sistema ShinodaLabs (casca)

- Zinc/black de base;
- Branco off-white para texto;
- Gradientes e glows no **acento do nicho**;

- Espaçamento generoso;
- Contraste forte;
- Pouca poluição;
- Microinterações discretas (hover no mockup, FAQ, botões).

## 27.2 Paleta de acento — tungstênio / luz quente de estúdio

Obrigatório diferenciar esta LP das demais por tokens CSS no wrapper `.photo-page`, no mesmo espírito de `.gym-page` (academias usam laranja energético; esta usa o acento abaixo).

Tokens de partida:

```css
.photo-page {
--law-accent: #e8b84a;
--law-accent-hover: #f0c86a;
--law-accent-bright: #f8dc9a;
--law-accent-deep: #b88a28;
--law-accent-grid: #ecbe58;
--law-on-accent: #1a1408;
--law-glow: #8a6a20;
--law-bg: #10100e;
--law-surface: #1a1916;
--law-muted: #b4aea4;
}
```

Por que estas cores: Âmbar de tungstênio evoca iluminação de estúdio, revelação e hora dourada — o acento de quem vive de imagem, distinto do latão imobiliário e do cobre de beleza.

O mockup do produto (o site do cliente) pode puxar mais o universo visual do nicho. A casca da LP permanece ShinodaLabs + acento.

## 27.3 O que NÃO fazer

Sem câmeras 3D, diafragmas girando, watermarks falsos, galeria masonry que destrói o LCP da LP da ShinodaLabs.

A identidade visual deve continuar sendo ShinodaLabs.
