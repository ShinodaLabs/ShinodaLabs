# PROMPT — LANDING PAGE DE ALTA CONVERSÃO PARA ADVOGADOS | SHINODALABS

## 1. CONTEXTO DO PROJETO

Quero criar uma landing page profissional, moderna e altamente otimizada para conversão, desenvolvida pela ShinodaLabs e destinada à captação de clientes para advogados e escritórios de advocacia.

A landing page será publicada especificamente em:

https://shinodalabs.com/landing-page-advogados

IMPORTANTE:
- A página pertence ao ecossistema da ShinodaLabs.
- A página será utilizada como destino de campanhas de tráfego pago da ShinodaLabs.
- O objetivo comercial da página é demonstrar uma solução de landing page especializada para advogados/escritórios e gerar leads interessados em contratar a ShinodaLabs.
- Não confundir o objetivo desta página com a captação de clientes jurídicos para um escritório. Aqui, o cliente da landing page é o ADVOGADO/ESCRITÓRIO que poderá contratar a ShinodaLabs.

A página deve funcionar como uma LANDING PAGE COMERCIAL DA SHINODALABS PARA O NICHO DE ADVOCACIA.

---

# 2. OBJETIVO PRINCIPAL

O objetivo principal é converter advogados e escritórios de advocacia que acessarem a página em leads comerciais para a ShinodaLabs.

O visitante deve entender rapidamente:

1. Que a ShinodaLabs cria landing pages para advogados e escritórios;
2. Que a solução foi pensada especificamente para o mercado jurídico;
3. Que uma landing page especializada é diferente de simplesmente possuir um site institucional;
4. Como a solução pode ajudar na estratégia digital e na geração de oportunidades;
5. O que a ShinodaLabs entrega;
6. Por que contratar a ShinodaLabs;
7. Qual é o próximo passo para solicitar um orçamento/conversa.

A página NÃO deve parecer um site institucional tradicional da ShinodaLabs.

Ela deve ser uma página de vendas/geração de leads B2B, porém com comunicação profissional, sofisticada e compatível com o mercado jurídico.

- Estratégia;
- Design premium;
